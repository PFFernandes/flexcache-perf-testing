# modules/04-managed-ad — AWS Managed Microsoft AD

The Active Directory domain for SMB. Created by `stacks/01-landing-zone` only when
`protocol = "smb"` in `common.tfvars`, in the origin VPC.

- **Two subnets in different AZs.** AWS always runs two domain controllers. The stack passes the
  first origin subnet plus an extra directory subnet in a second AZ (or the first two private subnets
  when `origin_azs` already has two).
- **Admin account:** the password is generated by the stack and stored in Secrets Manager as
  `<creator>-<project>/ad-admin`. The FSx for ONTAP SVMs join the domain with it (`stacks/02-fsxn`),
  and the Windows clients map the shares with it (`stacks/03-ec2`).
- **Cache side:** the directory's own security group gets the AD ports (DNS, Kerberos, LDAP, SMB,
  RPC) for each CIDR in `peer_cidrs`, so the cache SVM and the cache client can reach the domain
  controllers over the VPC peering.
- **Creation takes 20-45 minutes**, and so does deletion.

| Input | Default |
|---|---|
| `name`, `domain_name`, `short_name`, `admin_password`, `vpc_id`, `subnet_ids` | required |
| `edition` | `Standard` |
| `peer_cidrs` | `[]` |

**Outputs:** `directory_id`, `domain_name`, `short_name`, `dns_ips`, `security_group_id`,
`computers_ou` (the delegated OU the SVMs join, `OU=Computers,OU=<short_name>,DC=...`),
`fsx_admins_group` (`AWS Delegated FSx Administrators`).

**Tags:** the directory and its rules get the `Creator` tag and a `Name` starting with
`<creator>-<project>` (e.g. `pedro-flexcache-perf-ad`).
